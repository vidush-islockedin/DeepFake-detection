    Models used

    A convolutional face detector feeds a Vision Transformer. MTCNN is used as published; the transformer started from public deepfake weights that we fine-tuned on a free Kaggle GPU.

    1. Find faces

      MTCNN returns a box and 5 landmarks for every face it is at least 90% sure of.

    2. Crop

      A square 1.3 times the face, resized to 224 × 224, keeps the blend edges in view.

    3. Classify

      ViT-B/16 cuts the crop into 196 patches and outputs the chance of a deepfake.

    4. Decide

      The face is called a deepfake if its score reaches the cut-off.

    5. Explain

      Blur each part and score again; Grad-CAM shows where the model focused.

    Face detection · CNN

    MTCNN

    Multi-task Cascaded Convolutional Networks: three small CNNs in a row, each cleaning up the one before.

    P-Net
    12 × 12, proposes faces
    R-Net
    24 × 24, rejects false boxes
    O-Net
    48 × 48, box + landmarks
    Landmarks
    Eyes, nose, mouth corners

    Classification · Transformer

    Vision Transformer ViT-B/16

    Every 16 × 16 patch attends to every other, so it can compare the eyes with the jawline in one step.

    Good to know

    1. 1Evidence, not edits

      The maps show where the evidence was, not which pixels were changed.

    2. 2Known kinds of fake

      It learned the generators in A and B and the face swaps in C. A new kind of generator can still fool it.

    3. 3Small test set for C

      C is tested on fewer faces than A and B, so its accuracy is less precise.

    4. 4Any face decides

      A photo is called a deepfake if any face in it is. No face found means no verdict.
